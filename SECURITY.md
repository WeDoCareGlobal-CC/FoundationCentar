# Security Policy — We Do Care Global (org default)

## Supported Versions
All `main` branches of `agentguard, agent-eval, agentvault, enterprise-hybrid-rag, pharma-intelligence-os, FoundationCentar` — security fixes on latest minor.

## Reporting
Use GitHub Security Advisories on the affected repo, or email `emirperla96@gmail.com` with `[SECURITY]` subject.
Include version/commit, repro steps, impact. No live secrets in reports.

SLA: acknowledge 72h, triage 7 days, patch 14-30 days by severity.

## Out of scope
GitHub Pages demos (static), test keys, `Atlas-test-`.
