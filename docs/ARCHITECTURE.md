# Agentic Operations Architecture

## Authority hierarchy

Human CEO defines mission, risk tolerance, approval policy and business constraints.

AI Lead turns the mission into executable objectives, allocates budget, delegates work and evaluates verified outcomes.

Team Leaders own functional outcomes and coordinate workers: Revenue Lead, Product Lead, Research Lead and Ops Lead.

Workers perform bounded tasks such as research, prospecting, coding, QA, compliance analysis, finance reconciliation and support.

Verifier checks evidence, acceptance criteria, cost receipts and policy compliance before an outcome becomes verified.

## Economic loop

`Mission → Budget → Execution → Cost → Evidence → Verification → Revenue/Outcome → Learning`

## Local AI loop

`Cloud Control Plane → Mission Package → Local AI Runtime → Worker Execution → Receipt → Verifier → Control Plane`

## Research/release loop

`GitHub commit → GitHub release → Zenodo archive/DOI`

ORCID is the researcher identity layer. Public ORCID APIs can read public records; authenticated write operations require appropriate OAuth/member access.
