# One-Click Agent Factory

## Operating loop
CEO action → inferred mission → budget envelope → approval when required → dispatch → verification → append-only audit → learning.

## Real task boundary
This deployment provides a persistent orchestration loop and a local-worker receipt endpoint. External side effects remain approval-gated and require authenticated connectors. The system never fabricates proof of external completion.

## Expansion
Capability gap → Agent Spec → approval → sandbox/promotion path → org registry → audit.

## Emergency
Emergency Stop changes active/ready work to stopped and preserves records.
