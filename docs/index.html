FoundationCentar
One-Click Agent Factory OS

Autonomous multi-agent orchestration with human-in-the-loop CEO governance, bounded economics, and unified identity.

Apache 2.0 ORCID: 0009-0009-8515-2727 Version: v1.0.0 DOI: 10.5281/zenodo.23073888
Star on GitHub ↗ Quickstart → Live Demo ↗

The Problem

Multi-agent systems deadlock, spawn unbounded children, leak memory, and operate without human oversight. There's no standard for: How do I spawn agents safely? Who approves high-stakes actions? How do I bound compute and cost? How do I trace identity across agents?

FoundationCentar answers

  • One-click agent factory with Docker sandboxing
  • CEO governance layer — hierarchical HITL approvals
  • Bounded economics — token/memory/cost ceilings per agent
  • Unified identity — every agent traced to root
  • Evidence-first verification — every output auditable

Features

The operating system for governed multi-agent fleets.

Agent Factory

Spawn typed agents (researcher, coder, analyst, reviewer) with one CLI command or API call.

CEO Governance

Human-in-the-loop approval thresholds. High-stakes actions pause for review.

Docker Sandboxing

Every agent runs in a fenced container with memory, CPU, and network limits.

Unified Identity

Cryptographic agent identity chain. Every action traces back to root spawner.

Bounded Economics

Per-agent token budgets, API call limits, and cost ceilings. Auto-enforced.

Interactive Console

Web GUI for orchestrating meshes, viewing traces, and approving actions.

Quickstart

git clone https://github.com/we-do-care-global/FoundationCentar.git
cd FoundationCentar
pnpm install --frozen-lockfile
pnpm build
# Configure .env with your API keys
docker compose up -d
# Console at http://localhost:3000
# API at http://localhost:8080
